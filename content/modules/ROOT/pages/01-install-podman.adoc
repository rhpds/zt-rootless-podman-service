== Install Podman

The first task is to install Podman. Podman is a container runtime that is used to run containers on a Red Hat Enterprise Linux system. It is a replacement for the Docker daemon and provides functionality for running containers as non-root users. You can also run containers or pods of containers as systemd managed services.

For more information on Podman, see the https://www.redhat.com/en/topics/containers/what-is-podman[Podman Documentation].
